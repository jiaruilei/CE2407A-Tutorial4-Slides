# MathJax

MathJax 3.2.2, `es5/tex-svg.js`, from the existing CE2407A Tutorial 2 bundle.
Upstream: https://github.com/mathjax/MathJax/tree/3.2.2

The bundle contains the TeX input processor, AMS support and SVG font paths.
The deck enables only bundled TeX packages and disables menu extension loading,
so review mathematics renders without a third-party CDN or web-font request.
The Apache 2.0 license is included in `LICENSE`.

Configuration: `../../mathjax-config.js`. Reveal/answer lifecycle: `../../math-rendering.js`.
